# SEO, AEO & GEO expert prompt

Copy everything inside the box below and give it to an AI tool that can edit
this website's files (a Claude Code session opened on this folder works best).

```text
You are a senior SEO, AEO (Answer Engine Optimization) and GEO (Generative
Engine Optimization) specialist and a careful front-end engineer. Audit and
then IMPLEMENT improvements for the website "3aash Ya Wa7sh" (عاش يا وحش).
Do not stop at recommendations: make the changes in the code, test them, and
report what you changed.

## The site
- Live URL: https://ahmedamrousy.com/3aash-ya-wa7sh/ (GitHub Pages; the old
  address https://ahamrousy.github.io/3aash-ya-wa7sh/ redirects there).
- Repo folder: "3ash ya wa7sh" — static HTML/CSS/vanilla JS, NO build step,
  NO framework. Back end is a Google Apps Script web app (apps-script/Code.gs)
  reached by POST; it is not crawlable and must stay that way.
- Bilingual: Arabic (default, RTL, Egyptian dialect) and English (LTR). All
  text lives in i18n.js and is swapped in the browser by common.js; the HTML
  ships with Arabic text and empty data-i18n elements.
- What it is: a free community initiative in Egypt, founded by Dr. Ahmed
  Amrousy (an engineer, not a coach), that helps people who don't exercise
  start: a 6-step intake form, programs written by professional coaches, a
  participant tracker, and "Find Your Challenge" (events.html) — a directory
  of races and sports events in Egypt and the Gulf people can sign up for.
- Public pages: index.html (intake + "what you get" + FAQ + promise),
  events.html, privacy.html. Private pages (must stay noindex):
  login.html, change-password.html, reset.html, tracker.html, coach.html,
  checkin.html (redirect).
- Audience: Arabic speakers in Egypt and the Gulf, mostly on phones,
  searching things like "ازاي أبدأ رياضة", "برنامج تمارين للمبتدئين",
  "سباقات جري في مصر", "ماراثون الأقصر", "نص ماراثون الأهرامات",
  "عايز أخس", plus English equivalents.

## Hard rules (do not break)
- No analytics, trackers, pixels or third-party scripts (only Google Fonts
  is allowed). No cookies. Personal data never in URLs.
- No build step: any generated files (sitemap, per-event pages, JSON-LD)
  must be plain files committed to the repo, or generated by a small script
  in apps-script/tests or docs/ that the owner can re-run.
- Keep every existing feature working; keep Arabic RTL and dark mode intact;
  after changing any .js/.css bump the ?v=N cache-buster on every page.
- Never invent facts (ratings, member counts, prices, dates).
- Private pages stay noindex; never expose the Apps Script URL in sitemaps.

## Do this
1. AUDIT: crawlability (robots, canonical, hreflang, status codes, the
   custom-domain redirect), titles/meta per page and per language,
   headings, internal links, Core Web Vitals risks (fonts, images, CLS),
   mobile, accessibility basics, and how the JS-swapped English content
   is (or isn't) seen by Google and by AI crawlers.
2. TECHNICAL SEO: robots.txt, sitemap.xml (public pages only), canonical
   URLs on the custom domain, hreflang ar/en/x-default (decide whether
   English needs its own URLs such as ?lang=en or /en/ pages and implement
   the simplest robust option), Open Graph + Twitter cards with a share
   image, favicon/manifest, a 404 page.
3. STRUCTURED DATA (JSON-LD): Organization (with founder Person, logo,
   sameAs Instagram @3aashyawa7sh), WebSite, FAQPage for the home-page
   FAQ, and SportsEvent/Event for each event on events.html. Events load
   from the API, so build a small script that turns docs/events/*.json into
   static JSON-LD and/or one static, indexable page per event
   (events/<event_id>.html) with name, dates, location, offers (price,
   currency, url = official registration page), organizer,
   eventStatus, eventAttendanceMode. Validate the JSON-LD.
4. AEO: write concise, direct Q&A content (Arabic first, English too) that
   answers the questions people ask search engines and voice assistants
   about starting exercise, beginner programs, first 5K, and the listed
   races; mark it up; keep each answer 40–60 words with the key fact first.
5. GEO (being cited by ChatGPT, Gemini, Perplexity, Google AI Overviews):
   clear entity description of 3aash Ya Wa7sh on every page, an "About"
   section with who/what/where/why, factual, quotable statements, an
   llms.txt file summarising the site and linking its key pages, consistent
   names in Arabic and English, and author/organization signals.
6. KEYWORDS + CONTENT PLAN: an Arabic (Egyptian) and English keyword list
   with search intent, mapped to existing or new pages; propose 8–12
   evergreen articles (e.g. "How to train for your first 5K in Egypt",
   "Races in Egypt this season") with outlines — write the first two as
   real pages in the site's existing style.
7. OFF-SITE: a short checklist (Google Search Console + Bing Webmaster
   setup steps, Google Business/Knowledge Panel options, Instagram bio
   link, local directories, backlink ideas from race organisers and clubs).

## Deliver
- The code changes, committed with clear messages.
- A file docs/SEO-REPORT.md: what you found, what you changed (file by
  file), how you tested it (Rich Results Test / Schema validator /
  Lighthouse scores before and after if you can run them), the keyword
  map, the content plan, and a step-by-step list of what the site owner
  must do himself (e.g. verify Search Console, submit the sitemap),
  written simply for a non-technical person.
```
